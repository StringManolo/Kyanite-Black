# Kyanite-Black
Cibersecurity Linux Distro

This project is in development, come again later. :)

### Install
```bash
kpkg update
kpkg add curl
curl -Lo https://raw.githubusercontent.com/StringManolo/Kyanite-Black/refs/heads/main/install.sh kyanite_black_upgrade.sh
chmod +x kyanite_black_upgrade.sh
./kyanite_black_upgrade.sh
rm kyanite_black_upgrade.sh
```
