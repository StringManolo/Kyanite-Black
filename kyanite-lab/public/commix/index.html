Commix Command Injection Simulator

This public endpoint emulates a tiny fake Linux shell. It does not execute operating-system commands.

Simulation: selected harmless commands return predefined output. Unsupported commands return no output. Time-based injection is not simulated.

Simulated environment

Recognized commands include id, whoami, uname, pwd, hostname, ls, cat /etc/passwd, cat /etc/os-release, echo, and printf.
